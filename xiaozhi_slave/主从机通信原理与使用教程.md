## 二、ESP-NOW 通信原理

### 2.1 什么是 ESP-NOW？

ESP-NOW 是乐鑫开发的**无连接Wi-Fi通信协议**，具有以下特点：

| 特性 | 说明 |
|------|------|
| **无需握手** | 发送数据无需建立连接，类似蓝牙广播 |
| **低延迟** | 毫秒级传输延迟 |
| **低功耗** | 设备可休眠，唤醒即发 |
| **穿透性强** | 可穿透墙壁，有效距离200米+ |
| **与WiFi共存** | 可同时使用WiFi和ESP-NOW |

### 2.2 为什么需要先连接WiFi？

```
ESP-NOW 工作流程：
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  WiFi驱动初始化 │───►│  ESP-NOW初始化 │───►│  数据收发     │
│  (设置通道)    │    │  (绑定通道)    │    │  (点对点)     │
└──────────────┘    └──────────────┘    └──────────────┘
```

**关键点**：
1. ESP-NOW 依赖 WiFi 硬件，必须先初始化 WiFi 驱动
2. ESP-NOW 使用与 WiFi 相同的**无线通道**
3. 主从机必须在**同一通道**才能通信
4. 连接同一WiFi路由器可确保通道一致

### 2.3 通信数据包格式

```c
typedef struct {
    uint8_t command;      // 命令类型
    uint8_t device_id;    // 设备ID
    uint8_t gpio_index;   // GPIO索引
    uint8_t value;        // 数值
    uint8_t reserved[4];  // 保留字段
} iot_command_packet_t;   // 总共8字节
```

## 三、通信协议详解

### 3.1 命令类型

| 命令 | 值 | 方向 | 说明 |
|------|-----|------|------|
| `IOT_CMD_SET_GPIO` | 0x01 | 主机→从机 | 设置GPIO输出（开/关LED） |
| `IOT_CMD_GET_GPIO` | 0x02 | 主机→从机 | 查询GPIO状态 |
| `IOT_CMD_GET_ALL_GPIO` | 0x03 | 主机→从机 | 查询所有GPIO状态 |
| `IOT_CMD_HEARTBEAT` | 0x04 | 双向 | 心跳检测 |
| `IOT_CMD_RESPONSE` | 0x05 | 从机→主机 | 命令响应 |
| `IOT_CMD_DISCOVER` | 0x06 | 主机→从机 | 发现设备（广播） |
| `IOT_CMD_ANNOUNCE` | 0x07 | 从机→主机 | 设备公告 |
| `IOT_CMD_SET_SERVO` | 0x10 | 主机→从机 | 设置舵机角度 |

### 3.2 通信流程示例

#### 场景1：设备发现

```
主机                              从机
  │                                │
  │──── IOT_CMD_DISCOVER ─────────►│  (广播到 FF:FF:FF:FF:FF:FF)
  │                                │
  │◄─── IOT_CMD_ANNOUNCE ──────────│  (从机回复自己的MAC)
  │                                │
  │    记录从机MAC地址              │
  │                                │
```

#### 场景2：控制LED

```
主机                              从机
  │                                │
  │──── IOT_CMD_SET_GPIO ─────────►│
  │     gpio_index = 0             │
  │     value = 1 (开灯)           │
  │                                │
  │◄─── IOT_CMD_RESPONSE ──────────│
  │     gpio_index = 0             │
  │     value = 1 (确认)           │
  │                                │
```

#### 场景3：控制舵机

```
主机                              从机
  │                                │
  │──── IOT_CMD_SET_SERVO ────────►│
  │     gpio_index = 4 (servo1)    │
  │     value = 90 (角度)          │
  │                                │
  │◄─── IOT_CMD_RESPONSE ──────────│
  │     gpio_index = 4             │
  │     value = 90 (确认)          │
  │                                │
```

## 四、完整使用教程

### 步骤1：准备硬件

| 设备 | 数量 | 说明 |
|------|------|------|
| ESP32-S3 开发板 | 1 | 主机（运行小智AI） |
| ESP32 开发板 | 1+ | 从机（IoT控制） |
| LED灯 | 4 | 从机GPIO输出 |
| 舵机（可选） | 2 | 从机PWM控制 |
| 杜邦线 | 若干 | 连接GPIO |

### 步骤2：配置从机WiFi

编辑 `xiaozhi_slave/main/APP/Src/app_wifi.c`：

```c
// 修改为你的WiFi配置（与主机相同）
#define ROUTER_SSID      "你的WiFi名称"
#define ROUTER_PASSWORD  "你的WiFi密码"
#define MAX_RETRY_TIMES  5
```

### 步骤3：配置从机GPIO（可选）

编辑 `xiaozhi_slave/main/iot_slave_main.c`：

```c
// LED引脚
#define LED_GPIO_1      GPIO_NUM_2
#define LED_GPIO_2      GPIO_NUM_4
#define LED_GPIO_3      GPIO_NUM_5
#define LED_GPIO_4      GPIO_NUM_18

// 舵机引脚
#define SERVO_GPIO_1    GPIO_NUM_19
#define SERVO_GPIO_2    GPIO_NUM_21
```

### 步骤4：编译烧录从机

```bash
# 打开终端，进入从机目录
cd xiaozhi_slave

# 编译
idf.py build

# 烧录（替换COM口）
idf.py -p COM3 flash monitor
```

### 步骤5：获取从机MAC地址

烧录成功后，查看串口日志：

```

I (xxx) IOT_SLAVE:    IOT Slave Device Starting...
I (xxx) IOT_SLAVE: ========================================
I (xxx) IOT_SLAVE: Device MAC: AA:BB:CC:DD:EE:FF  ← 记录这个地址
I (xxx) IOT_SLAVE: WiFi 连接成功!
I (xxx) IOT_SLAVE: ESP-NOW initialized (channel 1)
I (xxx) IOT_SLAVE: ========================================
I (xxx) IOT_SLAVE:    IOT Slave Ready!
I (xxx) IOT_SLAVE: ========================================
```

### 步骤6：在主机注册从机

编辑 `main/boards/custom-esp32s3-cam/custom_esp32s3_cam.cc`：

```cpp
// 在 InitializeIot() 函数中添加
void InitializeIot() {
    if (Iot_Mcp_Init()) {
        ESP_LOGI(TAG, "IOT controller initialized");
        
        // 注册从机设备（替换为你的MAC地址）
        uint8_t slave_mac[6] = {0xAA, 0xBB, 0xCC, 0xDD, 0xEE, 0xFF};
        App_IOT_Add_Remote_Device("bedroom", slave_mac, 6);
        
        // 可以添加多个从机
        // uint8_t kitchen_mac[6] = {0x11, 0x22, 0x33, 0x44, 0x55, 0x66};
        // App_IOT_Add_Remote_Device("kitchen", kitchen_mac, 6);
    }
}
```

### 步骤7：编译烧录主机

```bash
# 回到项目根目录
cd ..

# 编译主机
idf.py build

# 烧录主机
idf.py -p COM4 flash monitor
```

### 步骤8：测试语音控制

确保主从机都已启动并连接WiFi，然后对小智说：

**控制LED**：
- "打开卧室的led1"
- "关闭卧室的led2"
- "把卧室的灯都打开"

**控制舵机**：
- "把卧室的舵机转到90度"
- "设置卧室servo1为45度"

## 六、常见问题排查

### Q1: 从机WiFi连接失败

**现象**：日志显示 "无法连接到热点"

**排查步骤**：
1. 检查SSID和密码是否正确
2. 确认路由器工作正常
3. 检查路由器是否设置了MAC过滤
4. 尝试将路由器通道固定为1

### Q2: 主机无法控制从机

**现象**：语音命令无响应，从机无动作

**排查步骤**：
1. 确认主从机连接同一WiFi
2. 检查从机MAC地址是否正确注册
3. 查看从机日志是否收到命令
4. 运行设备发现：`App_IOT_Discover_Devices()`

### Q3: 舵机不转动

**现象**：LED正常，舵机无反应

**排查步骤**：
1. 检查舵机供电（需要5V，ESP32的3.3V不够）
2. 确认信号线连接正确
3. 查看日志中的角度设置信息
4. 检查舵机是否损坏

### Q4: 通信距离不够

**现象**：近距离正常，远距离无响应

**解决方案**：
1. 确保天线连接良好
2. 减少障碍物
3. 考虑使用外置天线
4. ESP-NOW有效距离约200米（开放环境）

## 七、扩展开发

### 添加新的GPIO设备

在从机 `iot_slave_main.c` 中：

```c
// 1. 添加GPIO定义
#define RELAY_GPIO_1    GPIO_NUM_25

// 2. 增加MAX_GPIOS数量
#define MAX_GPIOS       7

// 3. 在Init_Gpios()中初始化
g_gpios[6].pin = RELAY_GPIO_1;
strcpy(g_gpios[6].name, "relay1");
g_gpios[6].state = 0;
g_gpios[6].type = GPIO_TYPE_LED;
```

### 添加新的命令类型

1. 在 `bsp_iot_controller.h` 添加命令定义
2. 在从机 `Process_Command()` 添加处理逻辑
3. 在主机添加对应的发送函数

## 九、安全建议

1. **添加ESP-NOW加密**：在生产环境中启用加密
2. **MAC地址白名单**：只接受已知设备的命令
3. **命令校验**：添加校验和或CRC
4. **心跳超时**：检测设备离线状态
