## 五、关键代码路径

### 主机端
- **文件**: `main\boards\custom-esp32s3-cam\custom_esp32s3_cam.cc`
- **工具注册**: `mcp_server.AddTool("self.iot.set_servo_by_index", ...)`

### 从机端(三楼) - 舵机角度验证
- **ESP-NOW接收**: `xiaozhi_slave_Thirdfloor\main\APP\Src\esp_now_receive.c`
  - case IOT_CMD_SET_SERVO
- **舵机控制**: `xiaozhi_slave_Thirdfloor\main\APP\Src\iot_control_task.c`
  - g_servo_angle_map[5] = {0, 35, 70, 135, 180}
- **枚举定义**: `xiaozhi_slave_Thirdfloor\main\APP\Inc\iot_control_task.h`
  - servo_angle_enum_t: SERVO_0=0, SERVO_35=1, SERVO_70=2, SERVO_135=3, SERVO_180=4

### 从机端(二楼) - 晾衣架
- **舵机GPIO**: GPIO19 (Servo 0)

## 六、晾衣架控制逻辑

### self.iot.clothes_rack 工具
| action | 角度 | 说明 |
|--------|------|------|
| hang | 180° | 晾衣服 - 晾衣架下降 |
| collect | 0° | 收衣服 - 晾衣架上升 |

### 从机接收验证 (三楼)
```c
if (servo_local_index < 2) { // 天窗 (GPIO18, 21)
    if (cmd->value == 0 || cmd->value == 35 || cmd->value == 70) {
        // 有效
    }
} else { // 晾衣架 (GPIO40)
    if (cmd->value % 45 == 0 && cmd->value <= 180) {
        // 有效
    }
}
```

---

## 七、注意事项

1. **三楼天窗角度**: 只接受 0/35/70° (gpio_index 6,7 对应 Servo 0,1)
2. **三楼晾衣架角度**: 只接受 0/45/90/135/180° (gpio_index 8 对应 Servo 2)
3. **二楼晾衣架**: 使用 index=0 (GPIO19)，接受 0/45/90/135/180°
4. **ESP-NOW通道**: 所有从机使用相同通道广播通信
5. **GPIO输出**: 所有GPIO输出都是高电平有效
