# ESP32 舵机角度调试操作文档（0~270°）

## 1. 你现在的代码结构

- 应用层接口：`App_Servo_System_Init()`、`App_Servo_Set_Angle(float angle)`  
  文件：`main/APP/Inc/app_servo.h`、`main/APP/src/app_servo.c`
- 角度核心逻辑：`Servo_Set_Angle(servo_t *servo, float angle)`  
  文件：`main/BSP/Inc/bsp_servo.c`
- 角度范围配置：`SERVO_MIN_ANGLE`、`SERVO_MAX_ANGLE`  
  文件：`main/BSP/Src/bsp_servo.h`

---

## 2. 接线说明（先确保硬件正确）

- 舵机信号线（黄/橙）-> ESP32 GPIO18（当前代码默认）
- 舵机电源正极（红）-> 外部 5V 电源正极
- 舵机地线（黑/棕）-> 外部 5V 电源地
- ESP32 GND -> 外部 5V 电源地（必须共地）

建议：
- 不要直接用 ESP32 的 5V/3.3V 给舵机供电
- SG90/270°舵机启动电流较大，电源建议 ≥1A

---

## 3. 代码里“多少度”是怎么生效的

你调用：

```c
App_Servo_Set_Angle(135.0f);
```

最终会走到 `Servo_Set_Angle()`，并做两件事：
- 先限幅到 `0~270`
- 再把角度映射为脉宽（500us~2500us）

当前映射公式（`main/BSP/Inc/bsp_servo.c`）：

```c
pulse = (angle / SERVO_MAX_ANGLE) * 2000 + 500;
```

含义：
- `0° -> 500us`
- `270° -> 2500us`
- `135° -> 1500us`

---

## 4. 最快上手：改 main.c 直接看角度

你现在的示例在 `main/main.c` 会循环 0° -> 135° -> 270°。  
如果你想改成指定角度测试，直接改成下面这样：

```c
void app_main(void)
{
    App_Servo_System_Init();
    App_Servo_Set_Angle(45.0f);
}
```

或分步测试：

```c
App_Servo_Set_Angle(0.0f);
vTaskDelay(pdMS_TO_TICKS(1000));
App_Servo_Set_Angle(90.0f);
vTaskDelay(pdMS_TO_TICKS(1000));
App_Servo_Set_Angle(180.0f);
vTaskDelay(pdMS_TO_TICKS(1000));
App_Servo_Set_Angle(270.0f);
```

## 5. 如何“校准到准确角度”

不同舵机的真实机械行程略有差异，建议做一次标定：

### 步骤 A：找安全端点
1. 上电后先设 `App_Servo_Set_Angle(135.0f)`（中位）
2. 再分别测 `0°` 和 `270°`
3. 若端点抖动、卡死、异响，说明脉宽过大或过小

### 步骤 B：调整脉宽范围
在 `main/BSP/Inc/bsp_servo.c` 里这行：

```c
pulse = (angle / SERVO_MAX_ANGLE) * 2000 + 500;
```

把 `2000` 和 `500` 改成你的舵机更合适的值，例如：
- 保守一点：`600~2400us`  -> `*1800 + 600`
- 行程更大：`500~2500us`（当前）

### 步骤 C：复测关键角度
至少验证：
- 0°
- 90°
- 135°
- 180°
- 270°

如果有偏差，再微调端点范围。

## 6. 常见问题

### 1) 舵机抖动
- 供电不足最常见
- 电源地没有和 ESP32 共地
- 信号线过长且无屏蔽

### 2) 角度不准
- 舵机本体齿轮间隙、机械臂装配偏差
- 端点脉宽不匹配，需要按第 5 节校准

### 3) 到不了 270°
- 舵机型号虽然写 270°，实际可能只有 250°~270°
- 机械限位提前触发，先减小端点脉宽再试

---

## 7. 你常用的两个入口

- 初始化：`App_Servo_System_Init();`
- 设角度：`App_Servo_Set_Angle(xxx);`

只要改 `xxx`，就是你要的目标角度（当前支持 0~270）。
