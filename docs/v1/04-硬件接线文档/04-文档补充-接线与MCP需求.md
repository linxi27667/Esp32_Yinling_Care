# 三楼从机功能补充文档

## 一、新增硬件模块

### 1.1 烟雾传感器 (MQ-2)

| 项目 | 参数 |
|------|------|
| 模块型号 | MQ-2 |
| 检测气体 | 烟雾、丙烷、甲烷、氢气 |
| 工作电压 | 5V |
| 输出方式 | 模拟电压 (ADC) |
| 连接引脚 | ADC1_CHANNEL_0 (GPIO 1) |

**阈值配置：**
- 清洁空气：< 500mV
- 轻度烟雾：500-1500mV
- 火灾警告：>= 2500mV

### 1.2 雨滴传感器

| 项目 | 参数 |
|------|------|
| 模块型号 | 雨滴检测模块 |
| 输出方式 | 模拟电压 (ADC) |
| 连接引脚 | ADC1_CHANNEL_3 (GPIO 4) |

**阈值配置：**
- 干燥：> 3000mV
- 小雨：2000-3000mV
- 大雨：< 1000mV

### 1.3 求助按键

| 项目 | 参数 |
|------|------|
| 连接引脚 | GPIO 48 |
| 模式 | 外部上拉 (pull-up) |
| 触发方式 | 低电平触发 (按键按下为0) |

### 1.4 天问ASR PRO 语音模块

| 项目 | 参数 |
|------|------|
| 模块型号 | 天问ASR PRO |
| 连接方式 | UART1 (单线发送) |
| TX引脚 | GPIO 17 |
| 波特率 | 115200 |
| 用途 | 火灾报警/求助按键 语音播报 |

**指令协议（单字节）：**

| 指令 | 格式 | 说明 |
|------|------|------|
| 火灾报警 | `0x01` | 烟雾超标时发送 |
| 求助报警 | `0x02` | 求救按键按下时发送 |

## 二、新增软件模块

### 2.1 sensor_adc_task.c

统一传感器任务，合并了原来分散的烟雾、雨滴、求助按键检测逻辑。

**功能特性：**
- 统一采样周期：500ms
- 防抖处理：烟雾3次、雨滴2次连续超阈值才触发
- 只更新标志位，不直接操作硬件
- Flag-driven架构：硬件操作由Device_Refresh_Task执行

### 2.2 sensor_config.h

统一阈值配置文件，便于调试和修改。

**包含配置：**
- ADC通道定义
- 烟雾传感器阈值
- 雨滴传感器阈值
- 防抖计数配置
- 求助按键GPIO定义

### 2.3 ASR UART 模块 (bsp_asr_uart + app_asr_uart)

天问ASR PRO语音模块的串口通信驱动，采用**混合分层架构**：

| 层级 | 文件 | 职责 |
|------|------|------|
| BSP抽象层 | `bsp_asr_uart.h/c` | 纯逻辑，函数指针接口 |
| APP绑定层 | `app_asr_uart.h/c` | ESP32硬件绑定，UART1实例化 |

**API接口：**
```c
void App_ASR_UART_Init(void);        // 初始化ASR UART
void App_ASR_Send_Fire_Alert(void);  // 发送火灾报警 (0xFF 0x01)
void App_ASR_Send_Help_Alert(void);  // 发送求助报警 (0xFF 0x02)
```

## 三、任务架构

### 3.1 三楼从机任务清单

| 序号 | 任务名 | 优先级 | 栈空间 | 周期 | 职责 |
|:---:|--------|:------:|:------:|------|------|
| 1 | console_event_task | 10 | 8192 | 阻塞 | 调试串口输入（AI对话） |
| 2 | uart_event_task | 10 | 16384 | 事件 | UART0事件处理（AI语音） |
| 3 | Device_Refresh_Task | 3 | 4096 | 100ms | GPIO刷新（标志位→硬件） |
| 4 | Sensor_ADC_Task | 4 | 4096 | 500ms | 烟雾+雨滴+求助检测 |
| 5 | Heartbeat_Task | 5 | 3072 | 30s | 心跳包保活 |
| - | EspNow_Recv_Callback | 中断 | - | 事件 | ESP-NOW接收解析 |
| - | EspNow_Send_Callback | 中断 | - | 事件 | ESP-NOW发送回调 |

### 3.2 优先级分配原则

| 优先级 | 任务 | 分配理由 |
|:------:|------|----------|
| 中断 | ESP-NOW回调 | 硬件触发，最高实时性 |
| 3 | Device_Refresh_Task | GPIO刷新影响用户体验 |
| 4 | Sensor_ADC_Task | 安全检测，实时性中等 |
| 5 | Heartbeat_Task | 心跳30秒保活，实时性最低 |
| 10 | UART任务 | 调试/语音，人工响应 |

## 四、自动联动逻辑

### 4.1 雨天自动收衣服

```
Sensor_ADC_Task (检测雨滴)
        ↓
g_device_flags.rain_status = RAIN_STATUS_HEAVY
        ↓
Device_Refresh_Task (100ms轮询标志位)
        ↓
检测到 rain_status != RAIN_STATUS_DRY
        ↓
自动将窗帘( SERVO_2 )设置为关闭 (SERVO_180)
```

### 4.2 火灾报警联动

```
Sensor_ADC_Task (检测烟雾)
        ↓
g_device_flags.fire_status = FIRE_STATUS_CONFIRMED
        ↓
App_ASR_Send_Fire_Alert() → UART1发送 0x01
        ↓
ASR PRO 语音播报 "火灾警报"
```

### 4.3 求助按键

```
用户按下求助按键 (GPIO48)
        ↓
Sensor_ADC_Task (500ms轮询GPIO电平)
        ↓
g_device_flags.help_status = HELP_STATUS_ACTIVE
        ↓
App_ASR_Send_Help_Alert() → UART1发送 0x02
        ↓
ASR PRO 语音播报 "紧急求助"
```

```

│              ESP-NOW 中断回调                           │
│         (更新 light/relay/servo 标志位)                  │
└────────────────────────┬────────────────────────────────┘
                         │
┌────────────────────────┴────────────────────────────────┐
│              Sensor_ADC_Task (Priority 4)                │
│         (更新 fire/rain/help 标志位)                     │
└────────────────────────┬────────────────────────────────┘
                         │
┌────────────────────────┴────────────────────────────────┐
│              Device_Refresh_Task (Priority 3)            │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ 雨天自动收衣服逻辑                                │    │
│  │ if (rain_status != DRY && servo[1] != 180) {   │    │
│  │     servo[1] = 180;  // 关闭窗帘                 │    │
│  │ }                                               │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ 火灾报警逻辑                                    │    │
│  │ if (fire_status == CONFIRMED) {                 │    │
│  │     buzzer = ON;  // 蜂鸣器响                   │    │
│  │ }                                               │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │ 统一刷新GPIO                                     │    │
│  │ - light[] → GPIO输出                            │    │
│  │ - relay[] → GPIO输出                            │    │
│  │ - servo[] → PWM输出                             │    │
│  └─────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

## 七、调试说明

### 7.1 DEBUG_MODE

三楼代码中已内置调试宏定义：

```c
#define DEBUG_MODE  1
```

**调试功能：**
- GPIO47 按键：每按一次，舵机角度步进45度 (0→45→90→135→180→0)
- Sensor_ADC_Task：每3秒打印一次 ADC 采样值

**关闭调试模式：**
将 `iot_control_task.c` 和 `sensor_adc_task.c` 中的 `DEBUG_MODE` 改为 `0`

### 7.2 日志输出

| Tag | 内容 |
|-----|------|
| IOT_CTRL | GPIO刷新状态、舵机角度、雨天/火灾状态变化 |
| SENSOR_ADC | ADC采样值、烟雾/雨滴/求助触发 |
| ESP_NOW_RECV | ESP-NOW命令解析 |
| ESP_NOW_HB | 心跳发送状态 |

## 八、扩展建议

### 8.1 天问ASR PRO语音模块

如需接入天问ASR PRO模块进行语音控制，建议：

1. **硬件连接：**
   - UART1 (GPIO 43/44) 连接 ASR PRO
   - 波特率：115200

2. **软件实现：**
   - 创建 `asr_uart_task.c` 接收串口命令
   - 解析 ASR 指令并更新对应标志位
   - 可复用到现有 Flag-driven 架构

3. **建议命令：**
   - "打开窗帘" → `servo[1] = SERVO_0`
   - "关闭窗帘" → `servo[1] = SERVO_180`
   - "打开灯光" → `light[] = ON`
   - "关闭灯光" → `light[] = OFF`

### 8.2 OTA远程升级

如需实现OTA升级功能：

1. 启用 ESP32 的 OTA 服务
2. 创建 `ota_task.c` 处理升级流程
3. 建议优先级：6（业务优先级）
4. 栈大小：8192（需要HTTP下载）

### 8.3 低功耗优化

当前为全速运行模式，如需优化功耗：

1. **Tickless 模式：** 在 FreeRTOSConfig.h 中启用
2. **动态频率：** 根据任务负载调整 CPU 频率
3. **深度睡眠：** 在无任务时进入浅睡眠，通过 GPIO 唤醒
