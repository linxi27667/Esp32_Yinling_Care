## 高性能处理器（第1章）

### 1.1 概述

ESP32-P4搭载双核RISC-V高性能处理器，主频最高400MHz，具备强大的计算能力和丰富的外设接口。

### 1.2 特性

- 双核 RISC-V 处理器，主频最高 400 MHz
- 带 AI 指令扩展
- 硬件浮点单元
- 另有 40 MHz 低功耗内核

### 1.3 RISC-V标准ISA扩展支持

| 扩展 | 说明 |
|------|------|
| M扩展 | 整数乘除法扩展 |
| C扩展 | 压缩指令扩展 |
| F扩展 | 单精度浮点扩展 |
| Zc(Z)扩展 | 自定义压缩扩展 |
| A扩展 | 原子操作扩展 |

### 1.4 自定义指令扩展

- 硬件循环(HWLP)
- 处理器指令扩展(PIE)

### 1.5 存储器保护单元

- 标准物理存储器保护(PMP)
- 自定义物理存储器属性(PMA)检查器

### 1.6 调试和追踪

- JTAG调试支持
- 调试暂停组
- 硬件触发器
- 追踪功能

### 1.7 性能特性

- 分支预测
- RAS (Return Address Stack)

## 低功耗处理器（第3章）

### 3.1 概述

ESP32-P4配备低功耗处理器(LP CPU)，用于在低功耗模式下执行简单任务，实现超低功耗待机。

### 3.2 特性

- 40 MHz 低功耗内核
- 独立的电源域
- 支持多种唤醒源

### 3.3 睡眠和唤醒流程

- 支持多种唤醒源
- 拒绝睡眠机制

## 通用DMA控制器（第4章）

### 4.1 概述

GDMA控制器支持存储器到存储器、外设到存储器、存储到外设的数据传输。

### 4.2 特性

- GDMA-AHB 和 GDMA-AXI 两种类型
- 链表传输模式
- CRC校验计算功能
- 事件任务矩阵功能

---

## 系统和存储器（第7章）

### 7.1 概述

ESP32-P4具有复杂的存储器组织结构，支持内部存储器和外部存储器扩展。

### 7.2 主要特性

- HP 系统 768 KB 片上 SRAM
- 8 KB TCM 零等待访问
- 32 KB LP SRAM
- 支持外部 PSRAM
- Cache 支持

## 与ESP32-C6协同使用

ESP32-P4芯片本身不集成Wi-Fi/BLE功能，但推荐的开发板（如ESP32-P4-Function-EV-Board）已集成ESP32-C6-MINI-1模组，提供：

- 2.4GHz Wi-Fi 6
- Bluetooth 5 (LE)

这种组合方案充分发挥了ESP32-P4的高性能计算能力和ESP32-C6的无线连接能力，非常适合智能家居、边缘AI等应用场景。
