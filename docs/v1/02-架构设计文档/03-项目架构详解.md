# 小智AI项目架构详解

> 本文档详细解析小智AI开源项目的整体架构、双核任务分配、模块关系，以及你自定义的BSP/APP层如何融入其中。

---

## 〇、用户交互层详解（可选组件）

用户交互层是**高度可配置**的，所有组件都是可选的。通过 `config.h` 中的 `GPIO_NUM_NC` 可以禁用任何组件。

### 1. 按键系统

#### 可配置的按键类型

| 按键名称 | 配置宏 | 默认引脚 | 是否必须 | 功能说明 |
|---------|--------|---------|---------|---------|
| BOOT按键 | `BOOT_BUTTON_GPIO` | GPIO0 | ✅ 必须 | 启动时进入WiFi配置、正常运行时切换对话 |
| 触摸按键 | `TOUCH_BUTTON_GPIO` | GPIO_NUM_NC | ❌ 可选 | 触摸唤醒/切换对话 |
| 音量加 | `VOLUME_UP_BUTTON_GPIO` | GPIO_NUM_NC | ❌ 可选 | 单击+10音量，长按最大音量 |
| 音量减 | `VOLUME_DOWN_BUTTON_GPIO` | GPIO_NUM_NC | ❌ 可选 | 单击-10音量，长按静音 |

#### 按键逻辑详解

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           BOOT按键逻辑                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  设备状态 = Starting (启动中)                                               │
│  └──► 单击 BOOT → 进入WiFi配置模式 (EnterWifiConfigMode)                    │
│                                                                             │
│  设备状态 = 其他状态 (正常运行)                                              │
│  └──► 单击 BOOT → 切换对话状态 (ToggleChatState)                            │
│       ├── Idle → Listening (开始监听)                                       │
│       └── Listening/Speaking → Idle (停止对话)                              │
│                                                                             │
│  长按 BOOT (部分开发板支持)                                                  │
│  └──► 进入WiFi配置模式                                                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                           音量按键逻辑                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  VOLUME_UP (音量加)                                                         │
│  ├── 单击 → 音量 +10 (最大100)                                              │
│  └── 长按 → 音量设为 100 (最大音量)                                          │
│                                                                             │
│  VOLUME_DOWN (音量减)                                                       │
│  ├── 单击 → 音量 -10 (最小0)                                                │
│  └── 长按 → 音量设为 0 (静音)                                               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 按键代码示例

```cpp
// 在 custom_esp32s3_cam.cc 中

// BOOT按键初始化 (必须)
boot_button_.OnClick([this]() {
    auto& app = Application::GetInstance();
    if (app.GetDeviceState() == kDeviceStateStarting) {
        EnterWifiConfigMode();  // 启动时进入WiFi配置
        return;
    }
    app.ToggleChatState();  // 正常运行时切换对话
});

// 音量按键初始化 (可选，需要配置引脚)
volume_up_button_.OnClick([this]() {
    auto codec = GetAudioCodec();
    auto volume = codec->output_volume() + 10;
    if (volume > 100) volume = 100;
    codec->SetOutputVolume(volume);
    GetDisplay()->ShowNotification("音量: " + std::to_string(volume/10));
});

volume_up_button_.OnLongPress([this]() {
    GetAudioCodec()->SetOutputVolume(100);
    GetDisplay()->ShowNotification("最大音量");
});
```

#### 如何禁用按键

```c
// 在 config.h 中设置为 GPIO_NUM_NC 即可禁用
#define TOUCH_BUTTON_GPIO       GPIO_NUM_NC  // 禁用触摸按键
#define VOLUME_UP_BUTTON_GPIO   GPIO_NUM_NC  // 禁用音量加
#define VOLUME_DOWN_BUTTON_GPIO GPIO_NUM_NC  // 禁用音量减
```

### 4. 摄像头系统

#### 摄像头配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `CAMERA_PIN_D0~D7` | 数据线 | 必须配置 |
| `CAMERA_PIN_XCLK` | 时钟线 | 必须配置 |
| `CAMERA_PIN_PCLK` | 像素时钟 | 必须配置 |
| `CAMERA_PIN_VSYNC` | 垂直同步 | 必须配置 |
| `CAMERA_PIN_HREF` | 水平参考 | 必须配置 |
| `CAMERA_PIN_SIOD/SIOC` | SCCB(I2C) | 必须配置 |
| `CAMERA_PIN_PWDN` | 电源控制 | GPIO_NUM_NC (可选) |
| `CAMERA_PIN_RESET` | 复位 | GPIO_NUM_NC (可选) |

#### 摄像头是否必须？

**不是必须的！** 如果你的设备没有摄像头：

```cpp
// 在 custom_esp32s3_cam.cc 中
virtual Camera* GetCamera() override {
    return nullptr;  // 返回nullptr表示没有摄像头
}
```

## 二、双核任务分配详解

### ESP32-S3 双核架构

ESP32-S3 有两个 Xtensa LX7 核心，小智项目充分利用了双核优势：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           Core 0 (主核 - 协调者)                             │
├─────────────────────────────────────────────────────────────────────────────┤
│  任务名称              │  优先级  │  堆栈大小   │  功能                      │
├────────────────────────┼─────────┼─────────────┼───────────────────────────┤
│  main (Application)    │    10   │    默认     │  主事件循环、状态机        │
│  audio_input           │     8   │   6KB       │  音频采集、唤醒词检测      │
│  audio_output          │     4   │   4KB       │  音频播放                  │
│  opus_codec            │     2   │   24KB      │  Opus编解码                │
│  activation            │     2   │   8KB       │  激活/OTA任务              │
│  IDLE                  │     0   │    -        │  空闲任务、内存清理        │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                           Core 1 (辅核 - 计算者)                             │
├─────────────────────────────────────────────────────────────────────────────┤
│  任务名称              │  优先级  │  堆栈大小   │  功能                      │
├────────────────────────┼─────────┼─────────────┼───────────────────────────┤
│  Yolo_Task (你的)      │     5   │   16KB      │  YOLO人脸检测推理          │
│  IDLE                  │     0   │    -        │  空闲任务                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 为什么这样分配？

| 设计决策 | 原因 |
|---------|------|
| 音频在Core 0 | 音频需要实时性，与主循环协同处理语音交互 |
| YOLO在Core 1 | AI推理计算量大，独占一个核避免阻塞音频 |
| 主循环在Core 0 | 事件处理、网络通信需要快速响应 |

## 三、核心模块详解

### 1. Application (应用核心)

**文件位置**: `main/application.cc` / `application.h`

**职责**: 整个系统的大脑，负责：
- 状态机管理 (设备状态转换)
- 事件驱动主循环
- 协调各模块工作

**状态机流程**:
```
┌──────────────┐
│   Starting   │  设备启动
└──────┬───────┘
       │ 网络连接
       ▼
┌──────────────┐
│  Activating  │  激活/OTA检查
└──────┬───────┘
       │ 激活完成
       ▼
┌──────────────┐     唤醒词/按键      ┌──────────────┐
│     Idle     │ ──────────────────► │   Listening  │
└──────┬───────┘                     └──────┬───────┘
       ▲                                    │ 检测到语音
       │                                    ▼
       │         播放完成            ┌──────────────┐
       └──────────────────────────── │   Speaking   │
                                       └──────────────┘
```

**事件驱动机制**:
```cpp
// 主循环等待事件
while (true) {
    auto bits = xEventGroupWaitBits(event_group_, ALL_EVENTS, ...);
    
    if (bits & MAIN_EVENT_WAKE_WORD_DETECTED) {
        // 处理唤醒事件
    }
    if (bits & MAIN_EVENT_NETWORK_CONNECTED) {
        // 处理网络连接
    }
    // ... 其他事件
}
```

### 2. AudioService (音频服务)

**文件位置**: `main/audio/audio_service.cc`

**职责**: 管理所有音频相关功能

**内部任务**:
```
┌─────────────────────────────────────────────────────────────┐
│                      AudioService                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐  │
│  │ 音频输入任务  │───►│ 音频处理链   │───►│ 编码发送队列 │  │
│  │ (Core 0)     │    │ AEC/VAD/唤醒 │    │ (Opus编码)   │  │
```

## 七、如何扩展新功能

### 添加新的MCP工具

1. **在 custom_esp32s3_cam.cc 的 InitializeTools() 中注册**:

```cpp
mcp_server->AddTool("self.my_new_tool",
    "工具描述，AI会根据这个描述决定何时调用",
    PropertyList({
        Property("param1", kPropertyTypeString),
        Property("param2", kPropertyTypeInteger, 0, 100)  // 带范围限制
    }),
    [](const PropertyList& props) -> ReturnValue {
        auto param1 = props["param1"].value<std::string>();
        auto param2 = props["param2"].value<int>();
        
        // 调用你的功能
        My_Function(param1, param2);
        
        // 返回JSON结果
        cJSON* json = cJSON_CreateObject();
        cJSON_AddStringToObject(json, "result", "success");
        return json;
    });
```

### 添加新的BSP模块

1. **创建BSP层文件** (`main/BSP/Inc/bsp_xxx.h`):
   - 定义结构体和函数指针
   - 不包含硬件头文件

2. **创建APP层文件** (`main/APP/Src/xxx.c`):
   - 包含硬件头文件
   - 实现HW_前缀函数
   - 实例化对象

3. **在板级初始化中调用** (`custom_esp32s3_cam.cc`)

## 九、总结

### 架构核心思想

1. **事件驱动**: 主循环等待事件，响应式处理
2. **分层抽象**: Board层隔离硬件，BSP层隔离逻辑
3. **双核协作**: Core 0处理实时任务，Core 1处理计算任务
4. **MCP扩展**: 通过工具注册机制扩展AI能力

```
│  ┌─────────────────────────────────────────────────────────────────────┐   │
```
